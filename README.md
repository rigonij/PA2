# SilverHappy

Plateforme web mettant en relation des **seniors** et des **prestataires de services à domicile** (ménage, aide, etc.), avec back-office admin complet.

## Fonctionnalités
- Espaces dédiés : Senior, Prestataire, Admin
- Catalogue de services, planning et gestion des interventions
- Vérification/validation des prestataires (documents, autorisation)
- Facturation, abonnements et paiements via Stripe
- Messagerie, avis et signalements
- Notifications et génération de PDF (factures)
- Volet data science : génération de dataset, dashboards analytiques et modèle de Machine Learning (classification)

## Stack technique
- **API** : Go (REST)
- **Frontend** : PHP
- **Base de données** : MySQL
- **Infra** : Docker (environnements dev/prod)
- **Paiement** : Stripe
- **Data Science** : Python (Jupyter), pandas, ML (dashboards + modèle de classification)
